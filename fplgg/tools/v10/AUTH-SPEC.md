## Backend (Apps Script web app, in Code.gs)

- `doPost(e)`: body is JSON text (the client sends `fetch(url,{method:'POST',body:JSON.stringify(req)})` with NO content-type header — text/plain, no preflight). Parse `e.postData.contents`. Always respond `ContentService.createTextOutput(JSON.stringify(res)).setMimeType(ContentService.MimeType.JSON)`. Wrap everything in try/catch → `{ok:false,error:'…'}`. Also implement `doGet(e)` that returns `{ok:true,service:'emt',claimed:[…team names…]}` (handy for verifying the deployment in a browser).
- Secret: `PropertiesService.getScriptProperties()` key `EMT_SECRET`; create it on first use (`Utilities.getUuid()+Utilities.getUuid()`).
- Hash helper: `sha256hex(str)` via `Utilities.computeDigest(Utilities.DigestAlgorithm.SHA_256, str, Utilities.Charset.UTF_8)` → hex.
- PIN storage: script property `EMT_PIN_<team>` = sha256hex(secret+'|'+team+'|'+pin). Never write PIN hashes to the sheet (the sheet is public).
- Token: sha256hex(secret+'|tok|'+team+'|'+pinHash). Returned on claim/login; verified on save. (Changing the PIN invalidates old tokens — fine.)
- Lockout: script property `EMT_FAIL_<team>` = JSON `{n, until}`; after 5 wrong PINs lock for 10 minutes; reset on success. Return `{ok:false,error:'locked',retryMin:N}` while locked.
- Actions (req.action):
  - `claim {team,pin}` — team must be a key of the app's team list (validate against the Standings tab column `Team` or the Rosters tab `Team` column — read from the sheet, don't hardcode names); pin must be exactly 4 digits. Fails `{ok:false,error:'claimed'}` if a PIN already exists for the team. Success → `{ok:true,token}`.
  - `login {team,pin}` — verify; success `{ok:true,token}`; wrong → `{ok:false,error:'wrong'}`; unclaimed → `{ok:false,error:'unclaimed'}`.
  - `save {team,token,color,shape,photo,manager}` — verify token; validate `color` ∈ PALETTE ids and `shape` ∈ SHAPE ids (see lists below; hardcode the id lists in Code.gs), `photo` either '' (remove) or a string starting with `data:image/jpeg;base64,` and ≤ 45000 chars, `manager` optional display name ≤ 40 chars (plain text). Upsert a row in a `Managers` sheet (create the tab with a header row if missing): columns `Team | Color | Shape | Photo | Manager | Updated` (Updated = ISO timestamp). Success `{ok:true}`.
  - `reset {team,token}` — clears the profile row values (keeps the PIN). `{ok:true}`.
  - `status {}` — `{ok:true,claimed:[teams]}`.
  - Commissioner escape hatch: a plain function `adminResetPin(team)` runnable from the Apps Script editor that deletes `EMT_PIN_<team>` + `EMT_FAIL_<team>` so a mate who forgot his PIN can re-claim. Document it in the section comment.
- PALETTE ids: royal, sky, navy, amethyst, magenta, aurora, gold, crimson, tangerine, umber, forest, teal. SHAPE ids: shield, heater, roundel, pennant, hex.
- The sheet: use `SpreadsheetApp.getActiveSpreadsheet()` (the script is bound to the sheet — check how the rest of Code.gs opens it and do the same).
